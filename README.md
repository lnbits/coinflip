# Coinflip - [LNbits](https://lnbits.com) extension

Multiplayer coin flip betting. Create games where a set number of players pay to enter, and one winner takes all the pooled sats.

## How it works

Set up a coinflip with the number of players and entry fee. Once all spots are filled, the game flips and picks a random winner who receives the entire pot minus a small fee.

## Features

- Configurable player count (2 or more)
- Fixed entry amounts
- Automatic winner selection
- Fair random outcome

## Usage

1. Enable the extension in LNbits
2. Create a coinflip with player count and entry fee
3. Share the game link
4. Game starts automatically when all spots fill
5. Winner receives the pot
